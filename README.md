# Gift Karo – gifting for Indians abroad

Design assignment prototype: send a gift to a loved one in India, picked through a 5-card quiz.

- `index.html` – mobile website (home)
- `quiz.html` – quiz flow: details → 5 questions → AI thinking → personalised gifts
- `desktop.html` – desktop website (1440)
- `assets/` – images and animations

Open `index.html` in a browser. On a laptop the mobile pages show inside a phone frame.
